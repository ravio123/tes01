Kebijakan Privasi

Geodora menghormati privasi Anda. Berikut adalah kebijakan privasi kami:

  • Tanpa Login: Anda tidak perlu membuat akun untuk menggunakan aplikasi ini.
  • Data Lokal: Semua data (riwayat gambar, pengaturan) disimpan di perangkat Anda (localStorage).
  • Tanpa Server: Kami tidak menyimpan data Anda di server manapun.
  • Gambar: Gambar yang dihasilkan hanya disimpan di perangkat Anda saat Anda mengunduhnya.
  • API: Aplikasi ini menggunakan Pollinations.ai untuk menghasilkan gambar. Data prompt dikirim ke API mereka untuk diproses.
  • Cookie: Aplikasi ini tidak menggunakan cookie.

Panduan Penggunaan

Cara menggunakan Geodora:

  • 1. Tulis Prompt: Masukkan deskripsi gambar yang Anda inginkan di kolom teks.
  • 2. Pilih Style: Pilih gaya gambar yang diinginkan (Fotorealistik, Sinematik, Anime, dll).
  • 3. Generate: Klik tombol "Generate Gambar" untuk mulai membuat gambar.
  • 4. Unduh: Setelah gambar muncul, klik "Unduh Gambar" untuk menyimpannya.
  • 5. Buat Ulang: Gunakan tombol "Buat Ulang" untuk membuat variasi baru dari prompt yang sama.
  • 6. Salin Prompt: Salin prompt ke clipboard untuk digunakan kembali.

Tips: Semakin detail deskripsi Anda, semakin baik hasil gambarnya!

Tentang Geodora

Geodora adalah aplikasi pembuat gambar berbasis kecerdasan buatan yang memungkinkan Anda menghasilkan gambar berkualitas tinggi hanya dengan menulis deskripsi.

  • Versi: 2.0.0
  • Rilis: Juli 2026
  • Teknologi: Pollinations.ai API
  • Platform: Web & Android (WebView)
  • Lisensi: Freeware - Gratis untuk semua pengguna
